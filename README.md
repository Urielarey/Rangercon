# RangerCon

Sitio web de RangerCon, la convención de fans de Power Rangers. Landing page estática (HTML, CSS y JavaScript vanilla, sin frameworks ni backend).

## Estructura

- `index.html` — estructura del sitio
- `css/styles.css` — estilos
- `js/main.js` — interactividad (tabs, formularios, modales, etc.)

## Cómo verlo localmente

Abrí `index.html` en el navegador, o levantá un servidor simple:

```bash
python -m http.server 5500
```

Y entrá a `http://localhost:5500`.
